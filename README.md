## 🛠️ Stack Tecnológico

- **Frontend:** React 19 + [TanStack Start](https://tanstack.com/router)
- **Estilos:** Tailwind CSS v4 (Design System personalizado: *Space Grotesk*, *Inter*)
- **Despliegue & Cloud Functions:** Firebase Hosting + Firebase SSR Cloud Functions (Node 20)

### 🚀 Comandos de desarrollo

```bash
# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Compilar para producción (Firebase SSR)
npm run build:firebase

# Desplegar a Firebase Hosting y Functions
firebase deploy
```
